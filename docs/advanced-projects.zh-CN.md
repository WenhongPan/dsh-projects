# 高级项目模式说明

这份说明只讲用户能感知的行为。更长的英文 RFC 是工程设计记录，不需要普通用户阅读。

## 第一阶段已经实现：多文件夹项目

你可以在项目菜单中选择“组合文件夹”，把两个或更多已有 DSH Workspace 显示为一个项目。组合时需要指定一个“主文件夹”：从组合项目新建会话时，DSH 会在这个主 Workspace 中创建会话；其他 Workspace 的历史会话仍会一起显示在组合项目下。

这个功能不会：

- 移动、复制或删除任何文件夹；
- 迁移或复制聊天记录；
- 修改 Agent 的系统提示词；
- 让 Agent 自动读写项目记忆；
- 替换 DSH 的 Workspace 或 Session 数据库。

选择“拆分组合”后，原来的 Workspace 会重新分别显示，文件和聊天保持原样。

## 数据保存在哪里

当前只在对应 Desktop 或 Web profile 的浏览器本地存储中保存：格式版本、组合名称、成员 Workspace ID、主 Workspace ID。不保存聊天正文和绝对路径。旧的测试格式会自动迁移；如果将来安装了更新版本又降级，旧版会保留但不会擅自解释未来格式，避免覆盖新数据。

因此目前有两个明确限制：

1. Desktop 与 Web profile 不会自动同步组合设置；
2. 清除站点数据或卸载插件后，组合关系会消失，但原 Workspace、聊天和文件不会丢失。

## 暂时没有启用的能力

项目指令、`AGENTS.md`、项目记忆、Agent 写入项目文件和提示词注入仍处于设计阶段。它们会影响 Agent 行为和权限，必须以后单独开关、单独授权、明确展示冲突后才能实现，不能跟随多文件夹组合自动开启。
